# Product images

1. Identify the deliverable, aspect ratio, and whether the user supplied a packshot. A packshot that must stay recognizable calls for image-to-image. Use text-to-image for concepts where exact packaging is unnecessary.
2. Put existing product photos in the reference slot the live model documents. Write the scene around the product's materials, placement, camera, lighting and background. Keep packaging text, brand colors and distinctive construction explicitly fixed when the reference matters.
3. Use recommendation and preflight to check reference count, aspect ratio, output format and the account quote. Get approval for the task budget. When perfect logo or label text is required, plan to apply the original artwork in a deterministic editing step.
4. Generate one first pass. Check product fidelity, legibility, shadow direction and crop before planning variations. Return the selected artifact, task ID and any visible issues.
