# Compare models with one input

1. Choose common constraints before selecting candidates: the same prompt and reference roles, crop, duration, audio and output format where supported. Preserve a model explicitly named by the user. Describe incompatible settings before claiming a comparison.
2. Build and preflight each actual request separately. Compare account quotes for equivalent requests and use decimal USD amounts. Group estimates and explain any compromises. Get approval for both individual ceilings and the combined budget.
3. Start only the requests covered by that budget. Keep each model ID, revision, task ID, and output together. Leave pending requests attached to the original IDs.
4. Return the artifacts, actual comparable settings and reported charges. Assess specific criteria such as word accuracy, reference fidelity, motion continuity and output time. State any constraints that prevented a fair head-to-head comparison.
